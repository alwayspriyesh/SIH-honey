# Honey Chain - Project Documentation Pack

These documents are intended to be given to an AI coding agent such as Antigravity as the project's source of truth.

## Files

01_MASTER_BUILD_BRIEF.md
Defines the product scope, MVP, stack, screens, and definition of done.

02_DESIGN_SYSTEM.md
Defines the visual identity, colors, typography, spacing, shapes, motion, accessibility, and what to avoid.

03_UX_AND_SCREENS.md
Defines each screen and the intended user experience.

04_TECH_ARCHITECTURE.md
Defines the frontend structure, data flow, local storage, mock authentication, and future API boundary.

05_MOCK_DATA_SPEC.md
Defines the demo records and QR payloads.

06_ANTIGRAVITY_BUILD_INSTRUCTIONS.md
Defines the practical implementation order and coding constraints.

## Recommended Agent Instruction
Read all six documents before writing application code. Treat them as the source of truth. Do not add major features that are not required by the MVP.
